# PRANASETU AI
Voice assistant + live Arduino monitoring for:
- Intruder Detection
- Fire Detection
- Blue Carbon
- Green Algae Tree

## Install
pip install -r requirements.txt

## Run
python main.py

If Arduino is connected, set SERIAL_PORT in config.py.
If no Arduino is connected, the program runs in demo mode.

The assistant answers project questions from knowledge.json and can report live sensor status.
